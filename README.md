## 🛠️ Run it locally

Use **Node.js 22.12 or later**.

```bash
git clone https://github.com/AnandVB07/AnandPortfolio.git
cd AnandPortfolio
npm ci
npm run dev
```

| Command | Purpose |
| :--- | :--- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create the production build in `dist/` |
| `npm run preview` | Preview the production build locally |

### Make it your own

| File or folder | Contents |
| :--- | :--- |
| `src/data.js` | Project descriptions, technologies, and links |
| `src/components/Hero.jsx` | Opening scene and avatar presentation |
| `src/components/About.jsx` | Biography and education |
| `src/components/Contact.jsx` | Social links and contact form |
| `src/index.css` | Global styling |
| `public/assets/` | Avatar, illustrations, and project images |

### Deploy with Vercel

Import this repository into Vercel, or use its existing connected project. The included `vercel.json` configures:

- **Framework:** Vite
- **Build command:** `npm run build`
- **Output directory:** `dist`

Keep the existing `anand-vb.vercel.app` domain assigned to the connected project.

The contact form uses Web3Forms. If you fork the project, replace its access key with your own.

</details>
